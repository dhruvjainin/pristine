# Security

Pristine is a set of instructions plus two local Node scripts. The scripts read files you point them at, and `capture.mjs` opens URLs in a headless browser and installs Playwright into `~/.cache/pristine-capture`.

If you find a way for the skill or its scripts to run unexpected commands, exfiltrate data, or be steered by content on a captured page, report it privately through [GitHub security advisories](https://github.com/maddhruv/pristine/security/advisories/new) rather than a public issue. You'll get a reply within a week.
